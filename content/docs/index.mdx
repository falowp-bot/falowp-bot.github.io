## 最小插件

```kotlin
@Plugin(name = "回显", tag = "基础", desc = "回显一段文字")
class Echo {
    private val echo = message(Regex("回显\\s+(.+)")) { (text) ->
        sendReply("你说的是：$text", reference = true)
    }

    init { echo.register() }
}
```
